# Google Search Console Launch Guide - 4WHEELS Rent a Car

This document details the exact launch and indexing verification steps for Google Search Console (GSC).

## 1. Domain & Property Setup
1. Log into [Google Search Console](https://search.google.com/search-console).
2. Add Domain property: `4wheelsrentacar.pk` (or URL Prefix `https://4wheelsrentacar.pk`).
3. Complete DNS TXT record verification via domain registrar.

## 2. Sitemap Submission
1. Navigate to **Sitemaps** section in GSC.
2. Submit primary sitemap URL: `https://4wheelsrentacar.pk/sitemap-index.xml`.
3. Verify status shows **Success** and total valid URLs (40+ pages).

## 3. URL Inspection & Live Testing
1. Test production homepage URL: `https://4wheelsrentacar.pk/`.
2. Inspect key high-priority routes:
   - `https://4wheelsrentacar.pk/fleet/`
   - `https://4wheelsrentacar.pk/build-your-rental/`
   - `https://4wheelsrentacar.pk/rental-terms/`
   - `https://4wheelsrentacar.pk/self-drive-car-rental-lahore/`
3. Request indexing for new or updated URLs.

## 4. Rich Results & Schema Audit
1. Run [Google Rich Results Test](https://search.google.com/test/rich-results) on key pages.
2. Verify `AutoRental`, `LocalBusiness`, `BreadcrumbList`, and `FAQPage` JSON-LD schemas render without errors.
