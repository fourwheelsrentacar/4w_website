# 4WHEELS Rent a Car - Vehicle Photo Accuracy & License Review Matrix

*Last Verified: October 2026 | Document Version: 2.0*

This document tracks all primary customer-facing vehicle photographs used across the 4WHEELS Rent a Car website (`https://4wheelsrentacar.pk`), booking configurator (`/build-your-rental/`), fleet directory (`/fleet/`), vehicle comparisons, and Pakistan Vehicle Request Catalog.

## Strict Photographic Requirements
- **NO 2D Illustrations or Cartoon Vehicles:** All customer-facing cards and summary widgets use real photographic imagery.
- **WebP Format Standard:** All primary vehicle hero images and model-year shape images are stored as clean `.webp` assets under `public/vehicles/`.
- **Exact Generation Alignment:** Model year choices strictly map to the exact body generation sold in Pakistan (e.g., Kia Sportage QL vs Sportage L NQ5; Kia Carnival YP vs KA4).
